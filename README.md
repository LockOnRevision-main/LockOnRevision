# 🚀 LockOnRevision

> **An AI-powered revision platform that helps students study smarter through personalized learning, adaptive revision, and gamified progress tracking.**

LockOnRevision is designed to transform exam preparation into an engaging and personalized experience. By combining artificial intelligence, structured learning paths, progress tracking, and gamification, the platform helps students stay motivated while building stronger study habits.

Whether you're revising for an upcoming test or preparing months in advance, LockOnRevision adapts to your learning journey.

---

## ✨ Features

* 🤖 AI-powered study assistant
* 📚 Interactive Forge learning system
* 📅 Personalized study timetable generation
* 🏆 Competitive leaderboards
* ⚡ XP & Energy progression system
* 👤 Student profiles and achievements
* 📊 Revision progress tracking
* ☁️ Secure cloud synchronization
* 📱 Fully responsive experience
* 🔒 Secure authentication

## 🎯 Scoring System

```text
Total Score = XP + (Energy × 100)
```

The scoring system rewards both consistency and learning progress.
